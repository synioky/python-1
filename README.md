# Каталог фильмов

Домашняя работа по Python, задачи 1–22. Все функции и исходный список фильмов находятся в `catalog_analysis.py`.

Для запуска нужны Python 3.12 и uv. Зависимости uv установит сам.

Запускать из папки проекта.

```sh
uv run catalog_analysis.py
```

Проверка кода через Ruff.

```sh
uv run ruff check .
```

Программа выводит средний рейтинг, возраст фильмов, топ-3 и статистику по жанрам.
